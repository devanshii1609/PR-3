# 🎓 Student Data Organiser

> A powerful, menu-driven Python application for managing student records while demonstrating the practical use of Python's core data structures and programming concepts.

## 📖 Project Overview

**Student Data Organiser** is a console-based application developed in Python that allows users to create, manage, and analyze student records efficiently.

The project demonstrates:

- Dictionaries
- Lists
- Tuples
- Sets
- Functions
- Loops
- Conditional Statements
- String Manipulation
- Data Processing

## 🚀 Features

### ➕ Add Student
- Add Roll Number, Name, Age, Marks, and Hobbies
- Prevents duplicate student records

### 📋 Display Students
- View complete student records
- Calculate and display average marks

### 🔍 Search Student
- Search records using roll number

### ✏️ Update Marks
- Modify marks for existing students

### ❌ Remove Student
- Delete student records when required

### 📊 Statistics
- Total students
- Unique hobbies
- Hobby analysis using sets

### 🔤 String Operations
- Uppercase conversion
- Lowercase conversion
- Title case conversion
- Length calculation
- Reverse string display

## 🛠 Data Structures Used

| Data Structure | Purpose |
|---------------|---------|
| Dictionary | Store student records |
| List | Store marks |
| Set | Store hobbies and unique values |
| Tuple | Store immutable student ID |
